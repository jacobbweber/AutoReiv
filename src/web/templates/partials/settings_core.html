Reply limits

Every model reply stops at these limits instead of running on. Empty or 0 uses the default (32768 tokens, 7200 seconds). The token limit includes the model's thinking, applies to every model call (helper calls get at least 16384 tokens so a thinking model can answer), and is capped at a quarter of the model's context window. The seconds count from the model's first token, so waiting for a free slot or for the model to load does not count.

Waits for slow local models (loading, filling the context, long thinking, queueing behind other chats). Empty or 0 uses the default. Provider silence is how long a model server may send nothing, before its first word or between words (default 1800). A job phase or developer turn may take up to 21600 seconds; a helper call (gap analysis, distillation, Skill Studio drafts) up to 1800.

How many wiki searches or note lists an agent may make in one reply. After that it stops searching and answers with what it found, saying plainly when nothing matched. 1 to 50; empty or 0 uses the default (8).
